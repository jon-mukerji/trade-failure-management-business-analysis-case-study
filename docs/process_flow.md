# Process Flow

## AS-IS
```text
Failed-trade report received
→ Analyst identifies case
→ Checks multiple internal systems
→ Checks spreadsheets/files
→ Investigates cause
→ Records notes manually
→ Attempts resolution
```

### Main weaknesses
Fragmented information, manual records, unclear ownership, duplicate investigation risk, inconsistent prioritisation and limited management visibility.

## TO-BE
```text
Failed trade identified
→ Central case created
→ Priority assigned
→ One current owner assigned
→ Investigation
→ Notes recorded
→ Status updated
→ Resolution/root cause recorded
→ Management view updated
```

This is a fictional process designed for a learning/portfolio case study.
