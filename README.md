# Trade Failure Management System — Business Analysis Case Study

A simple **Business & Technical Analysis portfolio case study** based on a fictional investment-banking trade-settlement scenario.

> **Important:** This is a learning/portfolio simulation. The accompanying dataset is 100% synthetic and contains no real customer, counterparty, employee or bank data. The case does not represent BNP Paribas or any other financial institution.

## What this repository demonstrates

The project follows a complete BA storyline:

**Business Problem → Stakeholders → AS-IS → Pain Points → Requirements → TO-BE → User Stories → Acceptance Criteria → MoSCoW → UAT → Backlog → Future AI/ML Enhancement**

Start with **[CASE_STUDY.md](CASE_STUDY.md)** for the complete case.

## Scope

This repository focuses on Business Analysis rather than Python/SQL implementation. A separate NHS A&E analytics project is being used to demonstrate Python, SQL and Power BI skills.

The synthetic trade data remains here only to provide realistic fictional context for fields such as trade value, failure reason, assigned analyst, status and days outstanding.
